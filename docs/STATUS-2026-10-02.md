Working name **Smidge** (repo `Hunter-Boone/CompressItAll`, code prefix `cia`). This is the hand-back report for the first build day: what exists, how it was tested, what was skipped, and what only Hunter can decide. The spec is `docs/DESIGN.md`; deviations are in `docs/DECISIONS.md`; the per-decision audit trail is `.audit/build.tsv` on the NAS copy of the project folder.

## 1. What was built

**Engine (Rust, shared by desktop, CLI and browser).**
- `cia-core`: job model, limits (raw vs base64 budgets), per-message water-fill allocation, output naming, free-tier allowance, every user-facing sentence (`copy.rs`), presets loader.
- `cia-image`: decode/sniff, EXIF and ICC handling, photo-vs-graphic classification, mozjpeg / libwebp / oxipng / AVIF / palette-PNG candidates, log-size quality search with downscale rounds, SSIMULACRA2 tie-break, second-decoder verification, animated GIF.
- `cia-pdf`, `cia-office`, `cia-audio` (symphonia, FLAC, Opus; MP3/AAC through FFmpeg), `cia-archive` (exact ZIP writer, 7z, tar.zst/xz), `cia-video-plan` (bitrate ladder, two-pass targeting, retry maths with the DESIGN worked example as a unit test), `cia-ffmpeg` (signed download, verification, encoder detection with real test encodes, transcode runner, watchdog), `cia-license` (Ed25519 tokens, product keys), `cia-mozjpeg` / `cia-webp` / `cia-wasm-libc` (C codecs that build for wasm32).
- `cia-engine`: detection, inspection, planning with previews, the job runner (all-or-nothing per message, atomic no-overwrite output, packaging, job log), FFmpeg video backend with the H.264 chain and VP9 WebM fallback.
- `cia-cli`: `cia inspect | plan | compress | verify | matrix | presets | ffmpeg install|status|remove`. The matrix re-verifies every output with an independent decoder and exits non-zero on any honesty violation (a file claimed under the limit that is not).
- `cia-wasm`: the same engine for the browser, 11.0 MB wasm (3.65 MB gzip).

**Apps.**
- `packages/ui`: the three-step flow (drop, pick destination, compress), tier menus, custom size, advanced drawer, trim panel, settings, licences page, spotlight tutorial, update bar. Design tokens in `packages/tokens`, brand strings only in `packages/brand/brand.json`.
- `apps/desktop`: Tauri 2 shell, native pickers, FFmpeg setup flow, updater with channels.
- `apps/web`: Vite app with a worker pool, service worker, OPFS job folders, WebCodecs video pipeline (`packages/webvideo`, mediabunny) with H.264 or VP9, Opus audio when the browser has no AAC encoder.
- `apps/site`: Next.js licence API (Paddle webhooks, one-time email codes, product keys, device slots, token signing) with an in-memory DB and a Supabase adapter; 112 vitest tests.

**Pipeline.** `test.yml` (lint, licence freshness, Rust on 3 OSes, wasm, desktop builds on 3 OSes), `release-desktop.yml` (tag → signed bundles → draft release in the Downloads repo), `promote.yml` (channel JSON with rollout), `web.yml`, `site.yml`, `nightly-matrix.yml`. Licence inventory generated from cargo-about and license-checker into `packages/licenses-data/licenses.json` and `NOTICE.md`; CI fails if stale. cargo-deny bans GPL/LGPL/AGPL in the bundle.

**Repos.** `CompressItAll` (private, main), `CompressItAll-Downloads-staging` (private; becomes the public Downloads repo), `CompressItAll-Libraries-staging` (private; LGPL-only FFmpeg 7.1.5 build, release `ffmpeg-7.1.5-r1` for Windows x64, macOS arm64/x64, Linux x64, with an Ed25519-signed manifest). Keep the staging repos private until the name is final; flip them public afterwards so users can audit the FFmpeg build and fetch installers.

## 3. Decisions worth knowing

- Rust + Tauri 2, not Electron: the engine is one Rust codebase for desktop and wasm, and the installer is 12 MB rather than 100+.
- FFmpeg is never bundled. The desktop app offers a one-time download of our LGPL-only build from the Libraries repo, verifies an Ed25519-signed manifest and SHA-256, then test-encodes each listed encoder before trusting it. H.264 comes only from GPU or OS encoders; with none available and a destination that forbids WebM, the app refuses with a clear sentence instead of failing.
- The browser does video with WebCodecs. The engine still owns budgets, naming, size read-back and packaging, so web and desktop produce the same decisions.
- Honesty rule everywhere: a file is "Fitted" only if the bytes written, read back, are strictly under the limit and decode with a second decoder.
- Distribution stays on the ConvertSave model: private monorepo, a public Downloads repo (GitHub Releases host the installers and the `channels/*.json` the updater reads, with rollout percentages via `promote.yml`) and a public Libraries repo (reproducible LGPL FFmpeg builds anyone can audit). The alternative considered was hosting installers on Cloudflare R2 behind the site domain: nicer URLs and no GitHub quota, but it hides the build provenance that the public repos give for free and adds a second credential set. Not worth it until download volume or GitHub limits say otherwise; the channel JSON already abstracts the URLs, so moving later is a one-line change per asset.
- Free tier is 3 files per 24 h; Pro is Lifetime or Yearly via Paddle; licence tokens are Ed25519-signed and valid offline for 45 days; product keys are optional and ConvertSave-style.

7. **Accounts**: Supabase project, Cloudflare (Pages + DNS), Vercel, Resend sending domain. Fill `apps/site/.env.example`.
8. **AAC posture**: the downloaded FFmpeg includes FFmpeg's built-in AAC encoder, as ConvertSave does. Confirm.
9. **Support mailbox**, and whether the ConvertSave portal also serves Smidge.
10. **Repo tokens**: `DOWNLOADS_REPO_TOKEN` (a fine-grained PAT with contents:write on the Downloads repo) so releases draft there; until then they draft into the main repo. The updater key has no password, so `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` can stay unset.
11. **Licence signing key**: run `cargo xtask keygen` before launch and replace the placeholder in `crates/cia-license/test-keys.json`; put the seed in the site's `LICENSE_SIGNING_KEY`.
12. **Make the staging repos public** once the name is final (Downloads and Libraries), so the FFmpeg manifest URL in `cia-ffmpeg/src/pinned.rs` resolves without a mirror.
